# Zainab Aljarrash – Personal Portfolio

A responsive personal portfolio website created for SWE 363 Assignment 1. It introduces me, presents my projects and interests, and provides a contact form and professional contact links.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension, or open it directly in a browser.

No installation, backend, or external dependencies are required.
